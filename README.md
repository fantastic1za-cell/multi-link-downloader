# Batch Media Downloader Dashboard

A high-speed batch downloader web dashboard built with Streamlit, yt-dlp, and Instaloader.

## Features
- **Batch Processing**: Input multiple links simultaneously.
- **Highest Quality**: Extracts maximum resolution video automatically.
- **Instagram Auto-Sorting**: Profiles go into `Instagram/[username]/`, single posts go to `Instagram/Media/`.
- **Custom Destinations**: Save directly to local storage, Google Drive, or OneDrive synced folders.
